# UNIVERSALIS-App

**Status:** Initial public scope baseline; proposed and awaiting review. No application implementation is claimed.

## Responsibility

UNIVERSALIS-App owns the public, user-facing UNIVERSALIS application experience: product requirements, workflows, interactions, and presentation. It consumes reviewed public interfaces and services from UNIVERSALIS-OS. It does not redefine OS policy or duplicate platform contracts.

## Migration destination

Legacy public UNIVERSALIS material belongs here when it specifies user-facing product behavior, application workflows, or presentation. Platform behavior, operating-system contracts, and shared public system architecture belong in UNIVERSALIS-OS. Each migrated artifact must retain its source provenance and receive one canonical destination.

Only public-safe, rights-cleared material may enter this repository. It must have no dependency on private C2O policy, identity, credentials, personal data, source paths, or operational evidence.

## Initial constraints and open requirements

- Follow published UNIVERSALIS-OS contracts and independent governance boundaries.
- Preserve privacy, human control, accessibility, and safe recovery in future requirements.
- Define product use cases, user roles, supported clients, and app-to-OS interfaces before implementation.
- Track source repository, path, revision, rights, and verification for every migration.

See `docs/preservation/APP_MIGRATION_INTAKE.md` for the proposed migration workflow.
